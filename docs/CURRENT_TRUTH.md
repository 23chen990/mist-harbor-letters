## 项目与技术边界

- 项目名：《雾港来信》。
- 当前项目是使用 Godot 4.x、GDScript 和 2D Control UI 制作的点击式人物询问 Demo。
- 商业与技术前提：Steam 买断、Godot 4。
- GDScript 负责剧情表加载、条件解释、知识状态和界面运行，不硬编码具体对白。
- 世界事实、角色私有知识、玩家知识与剧情状态必须彼此分离。
- 玩家未实际点击并看到、听到或主动问到的内容，不得写入玩家知识。
- 异象可以指向线索，但不能提供线索；进入推理链或参与结局兑现的内容必须形成唯物闭环。垂直切片不使用无法解释的异象额度。
- 写稿盘是核心机制；作品的核心不是选择剧情走向，而是选择愿意把什么写成事实。
- 全局分叉已按 `DEC-20260922-BRANCHING-UNFREEZE` 解禁，但结构限定为「菱形 + 场次池」，禁止树状分叉；累积式记账与「有且只有一次终局清算」不变。具体章数尚未确定。详见本文件「分叉结构」一节。
- 垂直切片范围是序章加第一章。

### Steam Demo 方向（`DEC-20260923-DEMO-REPORTER-INVESTIGATION`）

- Steam Demo 采用独立精选路线，不把完整第一章直接裁短。沈砚舟在玩家体验中同时承担两件相连的工作：调查自己能从材料与现场核对到什么，以及在来源不完整时决定什么能写进报纸、让谁知道、何时进入公众视野。
- Demo 的核心闭环是：玩家提出一条待核问题 → 通过问、看、犯忌或查纸取得有来源的原件/速记 → 决定信息流向与报道措辞 → 见报并看到编辑、人物、物证或可复核性发生后果。该闭环不新增第七个主角动词，也不把玩家变成已认证作者真相的全知侦探。
- 记者“调查真相”属于玩家可执行体验与材料组织方式；沈砚舟的作者层起点仍是接手可能值大版面的春和线，不新增“替赵敬文翻案”或“我要查真相”的主角自述。
- 第一章职业弧线按 `DEC-20260923-DEMO-CAREER-ARC` 固定为两阶段：S00 先表现稿位被撤、沈砚舟只争取继续跑春和线；林怀安死亡后，C17 空栏与“明天换人写”才让他意识到普通采访可能成为翻身机会；C18—C22 通过写稿强度与编辑收线表现这条线是否继续留在他手里。S00 不出现“头版”“大新闻”“几栏”等主控预知价值的措辞，不新增声望数值或记者身份危机。
- 完整第一章作者层顺序、林怀安必死、1917 不进事实判定、赵敬文案证据路径待确认等边界继续有效。具体 Demo 精选场次、目标说法、信息流 UI、写稿步骤与结尾停点在 `AI-TASK-20260923-DEMO-INFO-FLOW` 中继续审查，未在本摘要中预先补写。

## 主角与故事前提

- 沈砚舟不是赵敬文的儿子、亲属、门徒、崇拜者或遗志继承人。
- 沈砚舟是《雾港日报》一个混得不好的年轻记者；他与赵敬文在同一间编辑部共事过，但不熟。
- 两人分别姓沈、赵；不使用“本家”或其他关系说明对白。两人非亲属、非师承且共事不熟的作者层边界不变。
- 沈砚舟接手赵敬文死后没人愿意跑的选题；他接线是因为编辑把线交给他，而这条线可能值一个大版面。
- 沈砚舟的“混得不好”只指职业处境：长期没有做出大新闻、稿子屡遭退回、常跑没人抢的边角线；不自动包含他本人被欠薪、欠房租、饥饿、停职或失去记者身份。序章 S00 按 `DEC-20260908-34` 与 `DEC-20260923-DEMO-CAREER-ARC` 通过稿位被撤、无人接的春和线和编辑不保证下一篇稿位表现这一点；保持五句、两句主控回应，第二个回应为“材料给我看看。这趟跑完，明天还让我接着跑吗？”，不用心声自述动机。
- 沈砚舟熟悉雾港街面，但不熟戏班。
- 赵敬文 1917 年是二十五岁的年轻记者；沈砚舟 1937 年也约二十五岁。两人同龄的对应不得由文本、旁白或角色点明。
- 一句话故事：一个混不出头的记者接了一个死人留下的选题，最后发现那个人二十年前写错了一篇稿子，而他自己正要用同样的方式再错一次。
- 上一条是**作者层的主题判准**，用于检查稿子有没有走偏，**不是玩家侧的开场介绍，也不是沈砚舟的起点认知**。它描述的是故事最后落到哪儿；玩家要到很晚才会撞见这一层，主角本人整局都不会说出它。写宣发文案、开场提示或任何玩家可见文本时不得引用这一句。
- 玩家侧的开场前提（由 6.0 与 6.2 直接确认）：今晚的戏院采访只是一件没人要的普通活儿，编辑手边只剩沈砚舟才派给他；上一个跑这条线的老记者二十天前死在那儿，桌子还没清完。当晚班主死在侧台之后，这条活才可能变成他这辈子第一个大新闻。
- 主题结构：没有人完整地撒谎；每个人删掉自己知道的一半，而记者可能过早把残缺材料写成完整事实。

## 已确认前史与人物因果

- 1909 年老班主正常病逝，没有交接文书。他把戏箱与戏园房产留给女儿白素秋，并让方仲山“多担着”。
- 白家无子，白素秋继承的是物权；1909—1917 年间，方仲山实际承担过戏班经营。
- 方仲山从 1909 年起挪款；挂名顶股是约 1915—1916 年的晚近动作。两者不是同一件事。
- 白素秋要废除关书式班规，方仲山坚持保留。
- 白素秋在 1917 年冬去世；关于二十年前那一夜，不补直接物证，也不由系统认证玩家已经查明全部事实。
- 赵敬文二十五岁时写下的 1917 年报道，把残缺材料写成了延续二十年的错误结论。
- 方仲山在 1937 年秋使赵敬文落水，并用竹篙将仍活着的赵敬文按在水中直至其溺死；这项作者层真实经过不因公开结论改变。
- 警方与报纸把赵敬文之死认定为失足落水身亡；玩家初期只能把它当作有来源的公开结论，不能自动获得真实谋杀经过。
- 林怀安在 1937 年冬、白素秋二十年忌当夜死亡。作者层仍是 1937 年两桩谋杀；但原“精神状态提供者署名”证据链已随公开结论改变而失效，新的赵敬文案证据路径、并案支点与发稿顺序后果待确认。
- 陈九生知道玉棠动过药，并把药换回；这属于角色私有知识，不等于玩家知道。
- 天桥吊绳在台下必须留下可见的景片高度异常；第二天复位绳排的人是陈九生，不是凶手。
- 玉棠是 1917 年春出生、随母姓白。阿成是陈九生之子，出生于 1917 年。

## 分叉结构（DEC-20260922-BRANCHING-UNFREEZE）

- 结构只允许「菱形 + 场次池」。菱形指分叉持续一至两场后必须汇合回同一节点，汇合后状态不同、场次相同；场次池指同一章写 N 场、由玩家状态决定实际经历其中 M 场。禁止树状分叉。场次量按线性增长控制，全作由约 90–110 场预估增至约 140–180 场。
- 可分叉的只有四层：一、谁被钉死（由终局结算提前到第二章末，第三章的调查对象、可进场景与可得材料随之不同，第三章末汇合）；二、过程中谁被毁掉（阿成、许济川、小六等人被毁后真的退场，后续章节不再能从其处取材）；三、物证存亡（沿用吊绳复位样板，每章一至两处）；四、第二个死人（全作最多一个）。
- 不可分叉：林怀安在白素秋二十年忌当夜死亡，不受任何玩家选择影响；玩家递不递采访函只改变证据链与信息暴露速度，不改变凶案是否发生，沈砚舟仍拿到负罪感。1917 白素秋之死与赵敬文之死同样不可分叉。v6 第 5.1 节防分叉硬约束原样有效。
- 第二个死人必须由玩家事前可预见（沿用 6.4「风险当场可感知、后果不预告」的编辑泛化警告）；死者不得为沈砚舟。具体人选、触发条件与预警措辞仍为待确认项，不得自行补写。
- 良心轴的呈现：6.2 的「沉默主角」原样保留，不给沈砚舟内心独白评价自己刚做的事，不反省、不动摇、不自责，游戏不评价。同时把 8.5.2 结局重放中「这一篇见报之后发生了什么」由终局提前为每章开头的固定栏目，与 6.4 决定前的编辑泛化警告构成闭环。仍不设立场数值、道德条、进度条或独立 UI。
- 铺设纪律：必须先在序章加第一章做一个真分叉样板（优先用现成的吊绳线：告不告知警方 → 物证存亡 → 第二章能否复核），测出单个分叉点的实际工时与玩家手感，再决定全作铺设几个主干分叉点。样板未验证前不得批量铺分叉。
- 对白只进对话框（2026-09-22 已落入运行数据）：NPC台词列只保留说出口的句子；场面与神情写入画面指令，不进对白框。
