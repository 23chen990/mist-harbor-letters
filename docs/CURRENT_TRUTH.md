# 《雾港来信》CURRENT TRUTH｜R16.2

> 本文件是 R16.2 开发阶段的当前权威摘要。它只记录可由已确认的 R16.2 交接源直接确认的稳定事实与运行边界，不复制完整台词，也不把研究建议、旧实现或测试推断升级为剧情事实。

## 使用规则

- 详细对白与场次以 `docs/r16_2/source/雾港来信_R16.2_核心玩法与选择兑现版_全篇互动剧本.docx` 为准。
- 状态、节点、选择、条件、快照、报纸和结局路由以 `docs/r16_2/source/雾港来信_R16.2_程序接入表.xlsx` 为准；运行时只读取由确定性编译器生成的 JSON。
- `docs/DECISIONS.md` 记录 R16.2 切换及后续已确认决策。
- 根目录 v6 文件与 `docs/r16_2/legacy/` 仅用于历史追溯，不能覆盖 R16.2。
- v5、备份、旧测试、NPC 证词、研究文档和当前旧代码都不是 R16.2 事实源。
- 若 R16.2 正文、程序接入表或已确认决策彼此冲突，停止受影响的正式写入，列出冲突并标记“待确认”。

## 项目与技术边界

- 项目名：《雾港来信》。
- 当前目标是民国背景的剧情点击/文字推理解谜游戏，工程基线为 Godot 4.7、GDScript、2D Control。
- 核心体验：玩家先调查事实，再决定事实如何成为新闻，并看到报纸怎样改变人的生活。
- 制作层可以记录复杂的来源、许可、知识和生命周期；玩家层不显示好感、道德、信任或职业分数。
- 不新增第七个主角动词，不把报纸做成自由拼标题、拖拽排版或逐条来源管理器。

## 当前时间、地点与主要角色

- 时间：民国二十三年（1934）十月。
- 报馆：`《雾港晨报》`。
- 主要事件：玉棠台上倒下、药物链、周明远纸封、陈九生换药、许济川拿错药架并改记录、方仲山与戏班生计、阿成来源伦理。
- 主要角色与其身份、动机和详细前史以 R16.2 正文为准；不得从旧 v6 的赵敬文/林怀安线补写或拼接。

## 章节与固定流程

- CH1《纸封》：U01–U08。
- CH2《棕瓶》：U09–U15-B；U15 后必须先完成五卡药物链排序。
- CH3《谁欠谁》：U16–U23。
- CH4《见报》：U24–U32。
- 冷开场 D00 进入 D01；运行节点、选择、状态和条件由 R16.2 接入表驱动。

## 玩家交互上限

1. U08：两张完整标题卡二选一，再点“送排”。
2. U15-B：五张事件卡排序；错误只提示冲突相邻卡，不扣体力、不泄露完整顺序。
3. U27：三句话中点出一条当前不能直接刊的句子；错误回看采访原话。
4. U28：三张稿件卡三选一，后台自动组稿，显示整版报纸并确认交排。

禁止自由拼标题、拖拽排版、逐条来源/许可管理、道德/好感/职业分、失败扣体力和情绪场中的广告。

## 状态、知识与回溯

- story state 记录采访、人物知情、来源许可、承诺、稿件、日期、发行与阅读等；global exploration 记录已看分支、已解锁结局、剪报册和章节完成。
- 玩家知识必须由实际看见、听见或主动调查得到；角色私有知识和作者层事实不自动写入玩家知识。
- 普通选择使用选择前快照；D15-B 使用 `SS_U15_CHAIN`；D65-C 使用 `SS_U28_PREVIEW`；U32 两个选项共用 `SS_U32_FINAL`。
- 回溯只恢复 story state，不清除 global exploration、已解锁结局或剪报册。

## 报纸生命周期

生命周期固定为：

`draft → main_locked → auto_build → preview → typeset_confirmed → actual_published → delivered/read`

`确认交排` 不等于实际发行，实际发行不等于人物已读。off-record、匿名来源和未授权私密材料不得进入自动组稿结果。

## 结局与发行后果

- 主结局只有四个：E03、E04、E02、E01 fallback。
- 路由优先级固定为 `E03 → E04 → E02 → E01`。
- U32 的 `PIER/PRESS` 只改变收尾演出，不增加第五个结局。
- 剪报册只收藏实际发行过的报纸，不显示未解锁总数。
- IAA 只允许章节断点或玩家主动请求谜题提示；U11、U18、U25、U31、U32 禁止插入。
