# 《雾港来信》Steam Demo 精选路线提案

> 状态：工作提案；职业弧线部分已按 `DEC-20260923-DEMO-CAREER-ARC` 落地，其余路线仍需单独确认。本文不是 v6 正典，不新增剧情事实，不替代 `docs/DECISIONS.md`。
>
> 用途：把已确认的“记者一边调查，一边决定什么能成为公众事实”方向，整理成可评审的 15–25 分钟试玩节奏。时间是节奏目标，不是竞品官方时长声明。

## 目标

试玩结束时，玩家应该能复述四件事：

1. 我在核对哪一句材料；
2. 我亲眼留下了哪条现场记录；
3. 我把哪句话写进了报纸；
4. 谁因此知道了什么，以及我还想核对什么。

旧报中被铅笔重新标记的 1917 说法与林怀安当晚的 1937 现场问题并行存在。今夜现场可以写成有来源的待查报道，但不能反过来认证旧报真相。

## 本轮钩子复核（2026-09-23）

### 结论

「照常经侧台退场」是历史报道中的书面归因句。它能成为玩家之后回看的证据，却不能承担 Steam Demo 的第一记忆点：它没有当下的人、风险或可执行动作。把它换成另一句旧案摘要也不能解决这个问题。

首分钟需要先交付“一个活人今晚要面对的采访”和“玩家可以立刻做出的记者动作”，再让旧报细节变成玩家自己的假设。

### 推荐版本：未完成的采访 → 活人对峙

以下仍是提案，不回写 v6 作者层：

1. **S00 保留退稿与截稿压力。** 版面被抽走、编辑不给保版承诺，春和线作为赵敬文死后没人接的选题交给沈砚舟。这已经是具体损失和职业压力，不再用旁白解释“记者正在调查”。
2. **S01 把第一目标从“找齐原件”改成“决定先拿什么去问林怀安”。** 桌面仍可自由查看，但采访函应成为第一个可主动操作的对象：玩家看到赵敬文死前写下“其中一处说法想再向您核实”，点击【寻找回信】后得到范围受限的“报馆留底旁没有找到回函”。这不等于林怀安没回信。
3. **旧报与草图变成可选支持材料。** 旧报中的“照常经侧台退场”和草图中的“侧台—铁梯／散场？”都保留原样；系统不能替玩家宣布它们已经对应。玩家若主动把两者写进采访本，卡片标题应是“待核假设”，例如“散场后是否仍从侧台下台？”，而不是“赵敬文重查的是这条路线”。玩家也可以暂时不记。
4. **C04 尽早交付第一场活人冲突。** 现有台词“你来写戏，还是来重写旧报？”作为 Demo 首个强记忆点；之后沿用已有选择：交出函件、收回原件、只给抄录或只口述。反馈是林怀安看到什么、沈砚舟让谁知道了什么，不新增“林知道真相”的判断。
5. **C07/C09 再验证玩家自己的假设。** 只有玩家亲眼留下的 1937 现场速记，才能支持后面的路线句；这条记录不会把 1917 旧报变成已证实事实。C10 的药盒落地继续作为第一段可传播的即时异常。

### 首分钟验收

- 玩家无提示能说出：今晚要接手一场未完成的采访，并且知道下一步是选择材料、去问林怀安；
- 点击旧报后不会自动得到“下一步查纸、问人、看现场”的空泛提示；
- 玩家能区分“已有材料”和“我的待核假设”；
- 试玩记录不会把“照常经侧台退场”复述成 1917 已证实路线；
- C04 的交付/收回原件选择在旧报线索之后立即产生人物反应，记者的职业动作在首分钟内可见。

### 其他方案的定位

- “两篇报道并排”可以作为宣传镜头，但不能用构图或字幕替玩家并案；
- C10 药盒落地和 C07→C09 位置差异适合首段后半的动作异常，不能替代职业任务；
- 冷开到 C04 的反问可以另做 Trailer 测试，正式 Demo 仍应先保留退稿与截稿压力，让玩家知道自己为何接下这条线。

## 主控野心层复核（2026-09-23，已按 DEC-20260923-DEMO-CAREER-ARC 落地）

### 先求留下，再发现机会

v6 已经确认沈砚舟是一个长期拿不到大新闻、稿子常被退回的年轻记者；春和线在开场只是没人愿意接的普通活，他此时不知道这条线能变成大新闻，也没有资格先谈几栏版面。用户提出的“想通过这条线成为大记者”，应该写成一个**两段式变化**：开场先求不要被换掉，林怀安出事后才意识到这可能是他第一次真正的机会。

这份野心不通过“我要成名”的内心独白或单独的声望数值说明，而通过“摇摇欲坠的稿位 → 意外出现的大新闻 → 为保住报道而选择信息公开与稿面强度 → 这条线是否继续留给他”的连续动作表现。

### 已确认落法

1. **S00 先表现职业不稳。** 退稿稿页上的“撤”与编辑不给版面承诺继续保留。主控先问死者为何还在跑这条线，再把职业焦虑并进同一次取材料的动作；他只是在争取继续跑稿，不会提前询问版面或声望。

   当前正式落稿保持原有五句、三阶段和两次主控点击：

   > 编辑：春和今晚的采访，你去。赵老死后，这条线一直没人接。
   >
   > 沈砚舟：他死前还在跑春和？
   >
   > 编辑：跑了二十年。人也是在那儿没的。
   >
   > 沈砚舟：材料给我看看。这趟跑完，明天还让我接着跑吗？
   >
   > 编辑：在他桌上。十一点半截稿。明天的事，等稿子回来再说。

   这句合并回应明确稿位不稳，又不预设沈砚舟知道春和线能变成大新闻；不增加额外点击，也不使用“稿位”“版面”“头版”“几栏”等编辑部术语。
2. **S01 把材料选择变成一次勉强维持专业资格的行动。** 玩家决定带原件、抄录还是只记要点；此时不是为了争大新闻，而是为了不让这次采访继续变成一篇会被退回的普通稿。这个取舍沿用现有 C04 分支，不新增系统。
3. **C04 仍然是信息公开的第一次职业风险。** 玩家可以把旧报和草图摆到林怀安面前，也可以先只问回信、保留材料。林的反问“你来写戏，还是来重写旧报？”此时不是看穿主控的成名野心，而是质问一个刚接手死者选题的替补记者有没有资格动旧报。
4. **C10 让野心被事件唤醒。** 林怀安死亡后，上午那条没人要的采访突然拥有公共分量。到 C17，现有“春和那栏还空着。写不出来，明天换人写”才第一次把“这可能是我翻身的机会”变成玩家能感到的压力。
5. **C18—C22 给野心一个可见结算。** 玩家在安全事实与有来源的现场疑点之间选择；C22 已有两种结果：安全稿对应“明天换人写”，有现场疑点的稿对应“这栏出去了，明天别的馆也会去春和”。这条线是否继续留在沈砚舟手里，就是他第一次真正的职业晋级。
6. **旧报句承担主题回声。** 赵敬文当年也在二十五岁时把残缺材料写成长期结论；沈砚舟是在突然获得大新闻后，才面临“为了让报道有分量，是否把可写得更满误当成可以写成事实”的诱惑。这层关系留给玩家从材料和后果中发现，开场不由系统解释。

### 首章可见的野心闭环

```text
退稿稿位被撤
→ 接下没人要的春和采访，先争取不被换掉
→ 林怀安出事，普通采访突然变成可能的大新闻
→ 决定把多少材料交给采访对象
→ 选择安全报道还是有来源的现场疑点
→ 报纸发行后，编辑决定这条线是否继续留在你手里
```

这里没有独立“声望”或“成为大记者”数值，也不增加主角动词；野心由玩家实际做出的信息与稿面选择成立。

## 节奏草案

### 0–3 分钟：先给记者一场未完成的采访

- 复用：S00 报馆退稿、编辑派活；序章工作桌的二十年前旧报、采访函留底、旧戏院草图。
- 玩家动作：先读赵敬文写给林怀安的采访函，点击【寻找回信】；再由玩家决定是否查看旧报、草图，以及是否把“散场后是否仍从侧台下台？”作为自己的待核假设记入采访本。
- 即时反馈：采访函的范围受限翻找结果、原件收录、可回退的待核假设卡；任务从泛化的“找齐原件”变成“决定先拿什么去问林怀安”。
- 必留悬问：赵敬文想核实的究竟是哪一处？今晚林怀安愿意让记者知道多少？
- 跳过：把旧报句子自动升级为系统事实、把草图与旧报强行连成一条已证实路线、用“查纸、问人、看现场”代替玩家实际选择。

### 3–7 分钟：第一次决定信息给谁

- 复用：S02 函件准备与 C04 林怀安采访。
- 玩家动作：决定带哪些原件、先透露旧报与草图还是先谈采访函，再决定原件交出或收回。
- 即时反馈：林怀安的回答、原件是否离开报馆、采访本记录的来源范围发生变化。
- 记者感：玩家不是等待 NPC 讲完整背景，而是在决定对方能看到哪一页材料。
- 跳过：把所有材料自动串成主角内心总结；没有纸面依据的作者层动机不提前说。

### 7–12 分钟：现场取一条有代价的记录

- 复用：C05 阿成送灯、C06 演出中段、C07 谢幕前后。
- 玩家动作：在位置地图选择停留点，明确每处主要产出哪类信息（身体状态、前场缺席、台侧路线、人物关系），再选择一次第一眼观察。
- 即时反馈：采访本只写入玩家实际看到的速记；不选择的位置不补写。
- 可复述取舍：台侧 +「看倒下的位置」可以支持强位置句；只走来路并取得侧厅场务说法时，只支持窄位置句；陈九生与方仲山的记录必须保留主体。
- 跳过：单独的普通事实教学页、自动高亮正确位置、用位置标签提示“真线索”。

### 12–17 分钟：死亡发生后，问题换成“今夜能写什么”

- 复用：C08 侧厅无人、C09 第一眼、C10 药盒、C12 警方到场前调查；必要时保留 C14/C16 的短笔录观察。
- 玩家动作：在警察到场前选择复走来路、留在药盒附近或登天桥，并在写稿前回看实际速记。
- 即时反馈：药盒、路线、吊绳来源进入材料栏；来源不足时写法收窄，不能补齐未观察内容。
- 并行问题边界：这段只回答“1937 今夜发生了哪些可记录的异常”，不回答旧报中 1917 的事实。
- 跳过：重复解释死因、把 NPC 证词自动升级为作者真相、让玩家以无限回放拿回错过的位置。

### 17–22 分钟：把证据变成一句会流通的话

- 复用：C17 末版催稿、C18 第一篇稿、C19 是否写入赵敬文。
- 玩家动作：先选一项报道判断，再选支持该判断的现场记录；确认事实、位置强句/窄句、药盒窄句/强句、吊绳或具体人物离岗句。
- 即时反馈：C19 先显示稿面第二段和编辑即时反应；来源选择写入 `writing_source_id`，派生句子写入稿面预览。
- 写稿纪律：句子可以更强或更窄，但不会把 1937 记录写成 1917 认证；“谁知道什么”由交出原件、报纸公开和赵敬文关联三层决定。
- 跳过：固定词槽猜唯一答案、只显示“正确/错误”、让编辑替玩家逐句做决定。

### 22–25 分钟：见报有后果，留下一条继续调查的线

- 复用：C20 交稿、C21 次日见报、C22 编辑裁决与方仲山站位名单机会。
- 玩家动作：点击交稿，阅读实际写出的报纸正文；随后看到独立的“见报后的即时反应”，决定是否抄站位名单。
- 即时反馈：报纸正文保留强/窄句和具体主体；人物追问、绳排是否还能复核等后果放在独立反馈区，不伪装成报纸文字。
- 结尾悬问：方仲山交出的站位名单是否值得抄、这条线是否还在沈砚舟手里。试玩到这里结束，不进入尚未完成的第二章场次。
- 跳过：把“未拆信封”作为唯一冷钩子、在结尾替玩家总结旧案答案、提前实现赵敬文案证据路径。

## 与竞品开场节奏的对照

以下只引用公开页面能核对到的动作，不把媒体体验写成硬时长：

| 参照 | 开场交付 | 本 Demo 应对应的交付 |
|---|---|---|
| `The Case of the Golden Idol` | Steam Demo 开场即进入一宗现场案，玩家点击现场、得到身份信息，再提交自己的重建；媒体试玩还核对到后续案件递增。 | 采访函、材料选择和 C04 对峙应在前段交付一次“材料→问题→反应”；到 C18 之前至少完成一次“判断→来源”。 |
| `The Operator` | 试玩报道核对到职业工具、数据库/扫描等动作很早出现，并以电脑被入侵形成即时后果。 | 把查纸、问人、看现场作为职业动作；C21/C22 必须让公开稿件和编辑/人物反应立即可见。 |
| `The Roottrees are Dead` | 免费原版先搜索、识别并填入三姐妹，节点正确后自动推进；没有可靠官方首段分钟数。 | 每次调查选择都应留下一个可回指的记录，写稿后状态改变，不让材料只停在收藏栏。 |
| `Her Story` | 官方介绍的首动作就是在数据库输入关键词、得到片段，再用片段词语决定下一次搜索；它没有 Steam Demo。 | 采访函与回信查找应先给出可操作的下一问；旧报细节由玩家主动回看并形成假设。 |
| `Type Help` | 作者页确认是调查旧电脑文件；具体 `TYPE HELP` 顺序来自第三方提示页，不能当作者官方时长。 | 记者的下一步由上一份材料产生，但本作仍使用六个既有动词，不新增命令系统。 |

## 需要用户确认的正式项

以下项目在确认前只保留为提案，不回写 v6 作者文档、工作簿或生成 CSV：

1. 是否采用以上五段节奏作为 Steam Demo 的精选路线目标；
2. 是否把“未完成采访与材料选择 → C04 材料公开范围 → C18 来源写稿 → C21/C22 后果”定为试玩验收主线；旧报划线句降为支持材料；
3. C06 前场速记是否允许支持方仲山的中段离岗句，还是只用 C07 谢幕前后记录；当前运行层采用后者；
4. 是否把当前运行层已经验证的 C18 条件、药盒强/窄句、离岗主体句和 C21 稿面预览回写入口工作簿并重新生成运行数据；
5. 是否另行设计“谁知道什么”的可视化面板。当前实现用稿面、原件/速记栏和即时后果区表达，尚未新增独立知识图谱。
6. **已确认并已落地**：“先保住稿位、再因林怀安之死意识到这可能是大新闻”是沈砚舟第一章的可见职业弧线，采用“摇摇欲坠的稿位→意外出现的大新闻→信息公开取舍→稿面强度→编辑是否留线”的呈现链；不新增声望数值或内心独白。

其余尚未确认的路线选项仍需按 `AGENTS.md` 单独完成 `DECISIONS.md → CURRENT_TRUTH.md → 工作簿/同步器 → 代码与测试` 的正式同步。
