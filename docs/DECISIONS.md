# 《雾港来信》DECISIONS

本文件用于从现在开始记录已经明确确认的剧情与开发决策。它不代替 `docs/CURRENT_TRUTH.md`：前者记录“何时、由谁、为什么拍板”，后者汇总“当前有效的事实”。

## 记录规则

- 只有得到项目负责人明确确认的事项才能标记为“已确认”。
- 提案、讨论、推测和待选方案不得混入已确认记录。
- 每个决策使用唯一编号：`DEC-YYYYMMDD-NN`。
- 每条记录必须写明日期、状态、决策内容、依据、影响范围和被取代项。
- 若决策改变正式设定，应同时更新 `docs/CURRENT_TRUTH.md`；若改变实现，应列出需要同步的剧情表、代码、测试或资源。
- 后续决策取代旧决策时，不删除旧记录；把旧记录状态改为“已取代”，并互相引用编号。
- 本文件建立前已经散落在 v6 文档中的历史决定暂不重复回填，以免在没有逐项核对的情况下制造第二份不完整权威记录。

## 状态定义

| 状态 | 含义 |
|---|---|
| 已确认 | 当前有效，可以进入正式设定或开发实现 |
| 已取代 | 曾经有效，现已被另一条明确决策替代 |
| 已撤销 | 明确取消，且没有直接替代方案 |
