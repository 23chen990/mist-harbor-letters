## 项目与技术边界

- 项目名：《雾港来信》。
- 当前项目是使用 Godot 4.x、GDScript 和 2D Control UI 制作的点击式人物询问 Demo。
- 商业与技术前提：Steam 买断、Godot 4。
- GDScript 负责剧情表加载、条件解释、知识状态和界面运行，不硬编码具体对白。
- 世界事实、角色私有知识、玩家知识与剧情状态必须彼此分离。
- 玩家未实际点击并看到、听到或主动问到的内容，不得写入玩家知识。
- 异象可以指向线索，但不能提供线索；进入推理链或参与结局兑现的内容必须形成唯物闭环。垂直切片不使用无法解释的异象额度。
- 写稿盘是核心机制；作品的核心不是选择剧情走向，而是选择愿意把什么写成事实。
- 不设置第四章后的全局分叉；采用累积式记账，并且有且只有一次终局清算。具体章数尚未确定。
- 垂直切片范围是序章加第一章。

## 主角与故事前提

- 沈砚舟不是赵敬文的儿子、亲属、门徒、崇拜者或遗志继承人。
- 沈砚舟是《雾港日报》一个混得不好的年轻记者；他与赵敬文在同一间编辑部共事过，但不熟。
- 两人分别姓沈、赵；不使用“本家”或其他关系说明对白。两人非亲属、非师承且共事不熟的作者层边界不变。
- 沈砚舟接手赵敬文死后没人愿意跑的选题；他接线是因为编辑把线交给他，而这条线可能值一个大版面。
- 沈砚舟的“混得不好”只指职业处境：长期没有做出大新闻、稿子屡遭退回、常跑没人抢的边角线；不自动包含他本人被欠薪、欠房租、饥饿、停职或失去记者身份。序章 S00 按 DEC-20260908-34 通过稿位被撤、无人接的春和线和编辑不保证版面表现这一点；压缩为五句，沈砚舟由玩家点击追问、要求看材料，不用心声自述动机。
- 沈砚舟熟悉雾港街面，但不熟戏班。
- 赵敬文 1917 年是二十五岁的年轻记者；沈砚舟 1937 年也约二十五岁。两人同龄的对应不得由文本、旁白或角色点明。
- 一句话故事：一个混不出头的记者接了一个死人留下的选题，最后发现那个人二十年前写错了一篇稿子，而他自己正要用同样的方式再错一次。
- 主题结构：没有人完整地撒谎；每个人删掉自己知道的一半，而记者可能过早把残缺材料写成完整事实。

## 已确认前史与人物因果

- 1909 年老班主正常病逝，没有交接文书。他把戏箱与戏园房产留给女儿白素秋，并让方仲山“多担着”。
- 白家无子，白素秋继承的是物权；1909—1917 年间，方仲山实际承担过戏班经营。
- 方仲山从 1909 年起挪款；挂名顶股是约 1915—1916 年的晚近动作。两者不是同一件事。
- 白素秋要废除关书式班规，方仲山坚持保留。
- 白素秋在 1917 年冬去世；关于二十年前那一夜，不补直接物证，也不由系统认证玩家已经查明全部事实。
- 赵敬文二十五岁时写下的 1917 年报道，把残缺材料写成了延续二十年的错误结论。
- 方仲山在 1937 年秋使赵敬文落水，并用竹篙将仍活着的赵敬文按在水中直至其溺死；这项作者层真实经过不因公开结论改变。
- 警方与报纸把赵敬文之死认定为失足落水身亡；玩家初期只能把它当作有来源的公开结论，不能自动获得真实谋杀经过。
- 林怀安在 1937 年冬、白素秋二十年忌当夜死亡。作者层仍是 1937 年两桩谋杀；但原“精神状态提供者署名”证据链已随公开结论改变而失效，新的赵敬文案证据路径、并案支点与发稿顺序后果待确认。
- 陈九生知道玉棠动过药，并把药换回；这属于角色私有知识，不等于玩家知道。
- 天桥吊绳在台下必须留下可见的景片高度异常；第二天复位绳排的人是陈九生，不是凶手。
- 玉棠是 1917 年春出生、随母姓白。阿成是陈九生之子，出生于 1917 年。

## 写作与信息释放纪律

- 不新增人物间镜像或纯装饰性呼应。
- 至少保留两条能查清但与主题和案件无关的普通事实；第一条已确认是“戏班换角”，但按 `DEC-20260831-27` 不再作为当前 Demo 的独立教学页、热点或玩家知识写入。第二条尚未确定，不得自行补写。是否以后制作真正可操作的写稿盘教学，待确认。
