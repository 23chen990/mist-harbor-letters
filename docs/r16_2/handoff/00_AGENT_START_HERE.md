## 1. 当前正式开发目标

### 产品体验

《雾港来信》是一款民国背景的剧情点击/文字推理解谜游戏。

本轮 R16.2 的核心体验定义：

> 玩家先调查事实，再决定事实如何成为新闻，并亲眼看到这张报纸怎样改变人的生活。

核心循环：

`采访/观察 → 判断信息 → 轻推理闭环 → 决定报道方向 → 自动生成报纸 → 发行 → 人物/世界后果`

### 玩家层必须简单

制作层可以复杂，但玩家不能被迫学习报纸编辑器。

本版只保留四种特殊交互：

1. **U08**：两张完整标题卡二选一 → “送排”
2. **U15-B**：5 张事件卡排序
3. **U27**：3 句话中点出 1 句当前不能直接刊的
4. **U28**：3 张稿件卡三选一 → 自动生成整版报纸 → “确认交排”

明确禁止：
- 自由拼标题
- 拖拽排版
- 逐条管理来源/许可
- 复杂新闻编辑模拟器
- 道德值/好感值/记者职业分
- 失败扣体力
- 情绪场中插广告

### 章节

- CH1《纸封》：U01–U08
- CH2《棕瓶》：U09–U15-B
- CH3《谁欠谁》：U16–U23
- CH4《见报》：U24–U32

### 当前技术基线

继续以现有 **Godot 4.7 / GDScript / 2D Control** 工程为基线开发。  
本任务不要擅自换引擎或重做整个 UI 框架。

## 3. Agent 第一轮必须完成的事情

按顺序执行：

### A. 建开发分支
建议：
`r16.2-integration`

从当前 `main` / `baseline-20260919` 创建。不要改动基线 tag。

### B. 把本交接包资料纳入仓库
建议路径：

`docs/r16_2/`

至少保存：
- R16.2 全篇互动剧本
- R16.2 程序接入表
- 验收清单
- 修改对照
- 本交接文档

### C. 正式登记“新版取代旧 v6 作为当前开发目标”
必须更新：
- `docs/DECISIONS.md`
- `docs/CURRENT_TRUTH.md`
- `AGENTS.md` 的权威读取顺序
- `README.md` 当前实现说明
- `.github/workflows/ci.yml` 必入文件清单

要求：
- 旧 v6 文件可以保留做历史追溯
- 但必须明确标记为 **legacy / archive**
- 旧 v6 不能再成为 R16.2 的剧情事实源
- 不允许一边运行 R16.2，一边让 AGENTS 继续要求以旧 CURRENT_TRUTH 覆盖新稿

### D. 先做数据适配层，不要先抄剧情进 main.gd
现有工程的 `tools/xlsx_story_importer.gd` 只读一个 `剧情剧本` sheet、固定 21 列。
R16.2 接入表是多 sheet 状态机规格。

因此 **R16.2 XLSX 不能直接交给旧同步器**。

推荐做法：
- 保留 R16.2 XLSX 为作者/接入源
- 新增一个确定性的 build/compile 步骤
- 编译成客户端易读 JSON/资源数据
- Godot 运行时读生成数据，不在 `main.gd` 硬编码台词

建议生成结构至少包含：
- Nodes
- Choices
- StateDictionary
- Snapshots
- MicroPuzzles
- AutoArticleRules
- Endings
- Chapters
- NewspaperRenderSpec
- InterviewNotebookSpec
- EndingMontageRules

具体使用 Python 编译器或扩展现有 XLSX 解析器可以由 Agent 选择，但 **输出格式和行为必须符合 `RuntimeContract` + `ConditionDSL`**。

### E. 先跑一条完整路线，再铺全分支
先做到：

`D00 → U01 → ... → U32 → Ending`

要求：
- 文本完整可跑
- 选择暂停正确
- 条件显示正确
- 回退正确
- 最终报纸能看到
- 四种特殊交互先用占位美术也行

之后再做分支覆盖。

## 5. 什么叫“第一阶段接入完成”

- [ ] 新权威文档体系已经切到 R16.2
- [ ] 旧 v6 被明确降级为历史资料
- [ ] R16.2 数据可自动编译成运行数据
- [ ] D00–U32 至少一条路线完整跑通
- [ ] 选择节点不会被 `NextNode` 自动跳过
- [ ] U15/U27 谜题成功后才推进
- [ ] U28 自动组稿，不泄露 off-record/未授权材料
- [ ] 回溯只恢复 story state，不清除 global unlock
- [ ] `确认交排 ≠ 实际发行 ≠ 人物已读`
- [ ] 四结局按 E03 → E04 → E02 → E01 fallback 路由
- [ ] 新旧测试已分类，旧剧情断言不会被伪装成实现 bug
- [ ] 新 R16.2 smoke tests 通过
- [ ] 所有失败测试都真实报告

然后再进入美术替换、移动端适配、IAA 接入和真人试玩。
