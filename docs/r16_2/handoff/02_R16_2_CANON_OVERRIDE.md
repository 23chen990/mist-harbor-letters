# R16.2 正式口径切换说明

## 本文件用途

仓库现有 AGENTS 规范要求：正式剧情变化必须获得用户确认，并写入 DECISIONS/CURRENT_TRUTH 后才能落实现。

本次用户已明确：
- 当前 R16.2 新版继续制作
- 旧 Agent 仓库作为工程基础参考
- 新资料需要交接给 Agent 开发
- 后续以 GitHub 作为持续审查基线

因此本包中的 R16.2 是**本轮开发目标**。

## 旧版与新版不是兼容增量

旧仓库的作者层口径包括：
- 1937 / 1917 双时间
- 赵敬文、林怀安旧案
- 《雾港日报》
- v6 序章/第一章 C01–C22
- Steam 买断
- 旧写稿盘与旧案证据链

R16.2 的正式开发内容包括：
- 1934 年十月
- 《雾港晨报》
- 玉棠台上倒下事件
- 周明远纸封
- 玉棠主动动药
- 陈九生换药
- 许济川拿错药架并改记录
- 方仲山/婚事/戏班生计
- 阿成来源伦理
- U01–U32 四章
- 四种低复杂度互动
- 四个主结局
- 移动端 IAA 的情绪保护规则

这是剧情与产品定位的实质切换。

## Agent 必须执行的权威迁移

建议登记一条新决定，例如：

`DEC-20260919-R16_2-CANON-SWITCH`

内容至少写明：

1. R16.2 交接包成为当前开发目标。
2. 旧 v6 人物/信息树保留历史追溯，但不再覆盖 R16.2。
3. 旧 `CURRENT_TRUTH.md` 需要重写或归档，不能继续作为第一优先权威。
4. 新权威顺序建议：
   - `docs/r16_2/CURRENT_TRUTH_R16_2.md`
   - `docs/r16_2/雾港来信_R16.2_核心玩法与选择兑现版_全篇互动剧本.docx`
   - `docs/r16_2/雾港来信_R16.2_程序接入表.xlsx`
   - `docs/DECISIONS.md`
   - 旧 v6 仅 historical reference
5. 项目当前工程基线仍为 Godot 4.7。
6. 旧工程能力优先复用，旧剧情事实禁止混入。

## 建议的新 CURRENT_TRUTH 最小内容

不要把完整剧本复制进去。只写稳定事实：
- 时间、报馆、主要角色身份
- 核心事件因果
- 玩家/角色知识分离原则
- 四章范围
- 玩法交互上限
- 报纸发布状态机
- 四结局数量和路由
- IAA 禁止节点
- “制作层复杂，玩家层简单”的产品原则

详细台词仍以 DOCX / XLSX 为准。
