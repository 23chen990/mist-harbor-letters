# 《雾港来信》序章与第一章工作草案 v3

> 状态：工作草案；未经用户拍板，不进入正式母版。  
> 底稿：剧情信息树 v6；未列出的剧情、对白与事实继承 v6。  
> 边界：1917 不进入事实判定；第一章采访本只开放【原件】【速记】；不新增主角动词。

## 1｜相比 v2 改了什么

- S01 第一次写稿只教一件事：**证词能证明“说过什么”，不能自动证明“为什么离开”**。
- C05 只选一次基础观察位置；C06—C07 改为现场热点，不再连续弹出四选一菜单。
- C08 决定跟随或留守；C09 直接承接该路径的一次现场点击，不再二次选择“第一眼类型”。
- C12 在选择前给出环境中的时间压力，不显示倒计时，也不由 NPC 解释代价。
- C18 暂采用“无材料不能生成；有材料但关系越界可警告后交稿”的工作规则。
- C21 把后果落到具体句子、物证状态和人物反应，不使用抽象评分。

## 2｜当前最新版体验链

> 看一份口述材料，亲手收窄一句写过头的话  
> → 到春和后只选一次主要观察位置  
> → 随演出节拍点击该位置内的现场热点  
> → 在跟随与留守之间作一次路径取舍  
> → 死亡后看见警方将到，决定是否耗时上天桥  
> → 用亲自取得的材料写稿，也可以明知证据越界仍交稿  
> → 立即看到报道原句、物证状态和人物反应

## 4｜关键交互定稿方向

### S01：第一次写稿

不自由打字，也不让玩家从两条完整答案中二选一。

1. 稿纸上已有待核句：

   > 该角儿因月钱少离开春和。

2. 玩家把【班中人口述】拖到句子下，材料卡显示：

   > 两名班中人说，他离开前曾抱怨月钱。

3. 原稿句中的“因”仍无对应材料，系统只标红这个关系词：

   > 有人说过这件事；“因此离开”没有记录。

4. 玩家点击标红处，将因果收窄为：

   > 两名班中人称，他离开前曾抱怨月钱。

   来源称谓由材料自动带入，不再额外选择一次【注明来源】。

教学在这里结束。旧账和他园记录仍可查看，但不要求玩家再完成第二题；它们只让玩家理解“后来去了哪里”与“为什么离开”不是同一件事。

### C05—C07：一次选位，位置内观察

- C05 选择位置后锁定到本轮演出结束。
- 进入每个观察节拍时，镜头内亮起两个真实物件或人物热点；玩家点一个，另一个随节拍结束。
- 热点内容只重挂 v6 已有观察项，不新增事实。
- 记录页保留“我在哪里看见”与“我亲眼看见什么”，不显示漏掉的答案轮廓。

这样仍有取舍，但玩家感觉自己是在看台面、盯出入口或听人说话，而不是连续选择信息标签。

### C08—C09：去哪里，决定能看见什么

- 【跟过去】：更早到达，只出现身体或近旁地面的实体热点。
- 【留下查约见处】：先取得凉茶或镜布记录；死亡后晚到，只出现位置或人群热点。
- C09 不再弹出“身体 / 位置 / 人群”菜单。

### C12：可感知的机会成本

交互出现前，同一镜头同时呈现：

- 门口方向传来急促动静，现场人物开始回头；
- 通往天桥的梯子窄而长，往返显然需要时间。

不增加解释对白，不显示“将错过 C16”。玩家若仍上去，回来时警方已经控制现场，C16 自然关闭。

### C18：写稿盘规则

| 材料状态 | 写稿盘反应 | 玩家权限 |
|---|---|---|
| 没有取得相关材料 | 对应事实片段不生成 | 不能凭空选中 |
| 材料支持事实与关系 | 正常排入稿纸 | 可直接交稿 |
| 材料支持两件事，但不支持因果/动机 | 只标红越界词 | 可收窄；也可明确选择【仍按此措辞交稿】 |
| 涉及 1917 的未证实联系 | 只能写来源与待查状态 | 系统不生成“已经查明”表述 |

越界提交不是失败按钮，也不出现“善/恶、真/假”评分；代价通过 C21 的实际反应表现。

### C21：立即可见的后果

1. 先展示见报版面，并高亮玩家最终提交的原句，而不是系统总结。
2. 吊绳异常若已在 C15 报告并被封存，后续记录显示【已封存，可复查】；未报告时只保留记者速记，不自动补成警方证物。
3. 药盒若只写亲眼动作，后续仍按动作接受核查；若越界写成动机或因果，玉棠对本报记者转为【拒绝继续回应】，警方要求说明依据。
4. 若公开沈敬文联系，春和场景中的报纸直接出现该段，相关人物从此可以合理知情；若不公开，他们不能凭空知道。

以上均复用报纸版面、人物立绘、状态文字和现有场景，不新增 CG。

## 5｜继续保留

- S02 不恢复编辑对原件风险的提醒。
- C04 不恢复《夜渡》解释句，也不补同义对白。
- 命案不会因选择取消；一次性观察和报道取舍继续存在。
- 药盒只记录动作，不由系统推断下毒或毁证。
- 写稿盘仍是核心，采访本仍只有【原件】【速记】。
- 1917 不被系统认证，章末只形成下一步查纸目标。

## 6｜风险与待确认

### 风险

1. 每个位置的热点价值若不均衡，玩家仍会认为存在“标准答案位置”。
2. C12 的环境提示过弱会继续像隐藏惩罚；过强又会变成变相警告，需试玩调镜头时长。
3. 允许越界交稿会增加 C21 文本与状态组合，但这是写稿盘核心成本。
4. 玉棠拒访与警方追问必须短，不应扩成新的对白场。

### 待确认

- 正式规则是否采用：**教学必须收窄；正式写稿可在警告后越界提交。**
- C05 四个位置各自挂载哪些 v6 现有热点，需结合正式剧情树逐项校验。
- C12 门口动静的具体声音与镜头表达，留到演出稿确认。
- C21 的后果状态是否在第一章末全部展示，还是留一项到第二章开场兑现。
