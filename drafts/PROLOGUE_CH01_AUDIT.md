# 《雾港来信》序章 + 第一章审查报告

> 状态：工作审查，不是正式剧情或决策。  
> 审查对象：用户提供的《序章 + 第一章完整剧情信息树 v6》。  
> 边界：不覆盖正式母版，不改工作簿、CSV、Godot、`DECISIONS.md` 或 `CURRENT_TRUTH.md`。

## 1. 总体判断

现有版本的案件骨架、人物隐瞒结构和写稿盘方向成立，尤其是“只写实际获得的材料”“一句判断必须由现场记录支撑”“见报内容改变次日局面”三层，已经具备本作的差异化核心。

目前最影响 Demo 的不是案情需要重做，而是核心体验交付过晚、观察取舍缺少可预期性，以及几个戏剧峰值连续拿走玩家输入。玩家可能在读到 C18 前已经理解这是一个气氛和文本都不错的故事，却还没有确认“这是不是一个需要我推理、需要我承担报道后果的游戏”。

另有一组确定的版本错位：权威人物与前史 v6 的第 6.3、9.3、11.3 节已经要求补写稿盘教学、死亡钩子、同姓澄清、景片高度异常、蒙镜、单场时间代价、关键场次输入和章末主动抓手，但当前剧情树尚未吸收。这不是新提案，而是两份 v6 尚未同步。

本轮没有把竞品做法升级为项目规则。现有竞品库为空，因此只做了针对性参考：

- Jon Ingold 的 GDC 演讲把侦探游戏的短循环概括为“发现具体信息 → 玩家推断 → 玩家用行动证明自己理解了”，支持把写稿盘方法论提前到序章，而不是等 C18 才第一次操作。来源：[GDC Vault｜The Burden of Proof](https://www.gdcvault.com/play/1027723/The-Burden-of-Proof-Narrative)。
- 《The Case of the Golden Idol》开发访谈强调目标是让玩家通过玩法而非侦探题材包装获得侦探感，并通过反复测试调整“提示过多/过少”与推理是否可玩，支持将盲选位置改为“知道信息品类、但不知道具体答案”的选择。来源：[Game Developer｜Pursuing the “Aha!” moment](https://www.gamedeveloper.com/design/case-of-the-golden-idol)。
- Valve 要求独立 Demo 页面只展示 Demo 中实际能体验到的功能与内容，并使用 Demo 实际截图和预告素材。这意味着写稿盘、位置观察、犯忌和见报后果必须在切片里真实成立，不能只由商店文案承诺。来源：[Steamworks｜Demos](https://partner.steamgames.com/doc/store/application/demos?l=en)。

## 2. 最严重的问题

### P0-01｜核心写稿循环到 C18 才第一次可操作

- 所在场次：S01、C05—C07、C17—C18。
- 玩家实际体验：序章读材料，入场后继续读对白与做位置选择，但直到命案后回报馆才第一次知道“材料如何支撑一句话”。位置选择发生时，玩家尚未学会该收集什么，C18 的失败提示容易被理解为 UI 试错。
- 根因：旧采访本只讲方法，没有让玩家用写稿盘做一次低风险操作；核心动词“发稿”与证据—措辞关系交付过晚。
- 相关岗位判断：narrative＝核心玩法没有参与开场结构；playtest＝前 15 分钟缺少一次完整的主动认知循环；commercial＝Demo 卖点不能在早段被玩家亲手验证；continuity＝人物与前史 v6 第 6.3.1 已要求教学，剧情树未同步。
- 已有竞品/设计模式依据：GDC 的“发现—推断—证明理解”循环；《Golden Idol》“通过玩法而非题材包装产生侦探感”。现有项目模式库为空，本条仍是工作建议。
- 商业影响：玩家可能把 Demo 归类为线性视觉小说；写稿盘无法成为前 15 分钟记忆点，Trailer 也缺少早段可展示的核心操作。
- 建议修改方式：在 S01 的“戏班换角”旧案中复用写稿盘，做一次可跳过、零案件风险的短教学；先让玩家尝试写过满，再收窄措辞或补足材料。
- 制作成本：中。复用现有写稿盘与原件/速记卡，不新增系统、CG 或全局 UI。

### P0-02｜开场死亡钩子太晚，同姓关系未当场关掉

- 所在场次：S00、S01。
- 玩家实际体验：玩家先知道“沈老死前在跟这条”，但要主动点到死亡报道才知道他死在春和后巷；若先点其他物件，开场目标只是普通纪念演出采访。同时“沈砚舟/沈敬文”同姓会自然触发父子猜测。
- 根因：最强事实被放进自由探索的非固定点击顺序；v6 取消父子关系后的必要澄清没有落进剧情树。
- 相关岗位判断：narrative＝开场问题不够锋利；continuity＝存在 v5 语义回流风险；playtest＝前三分钟未稳定回答“为什么我要去”；commercial＝第一分钟 Hook 不稳定。
- 已有竞品/设计模式依据：不是竞品结论，直接来自人物与前史 v6 第 6.3 节的硬约束。
- 商业影响：开场截图和短视频只有“退稿+派普通采访”，无法一句话说明“死人留下的选题”。
- 建议修改方式：S00 由编辑补一句“他跑春和二十年，人也是在那儿没的”；S01 清桌途中由同事顺口问“你们是本家？”沈砚舟答“不是”，不加镜头。
- 制作成本：低。两处短对白，无新资源。

### P0-03｜位置系统是盲选，且 C05 前场会训练玩家避开它

- 所在场次：C03、C05—C07。
- 玩家实际体验：玩家不知道四个位置分别会产出什么，只能猜；第一次选择前场还明确“没有可用于本章推理的速记”，会立刻学到“前场是空选项”。
- 根因：位置没有稳定的信息品类；不同位置的价值不对称；取舍发生在玩家拥有决策信息之前。
- 相关岗位判断：narrative＝选择缺少可读意图；playtest＝不是有信息的赌注，而是抽奖；commercial＝核心交互在录屏中看起来只是换背景；production＝可用现有地图标签和阿成带路对白解决。
- 已有竞品/设计模式依据：《Golden Idol》访谈支持以测试校准提示量；本作最适合的改造不是给答案，而是告知“这里通常能看到哪类东西”。
- 商业影响：玩家可能把错过关键记录归咎于游戏，不会产生“是我选择看别处”的责任感。
- 建议修改方式：固定四类产出：观众席＝身体状态，前场＝调度与缺席，台侧＝空间路线，乐池＝人物关系；C05 前场的旧木箱位置成为可复核锚点，不再是空信息。
- 制作成本：低到中。补地图描述、速记与少量后续状态，不增加场景。

### P0-04｜旗舰吊绳线索没有台下指路信号

- 所在场次：C05、C06、C12、C18。
- 玩家实际体验：玩家先被明确告知“天桥不见生人”，之后只能在三个警方到场前选项里无提示地猜“上天桥”最有价值。没猜中就错过本章唯一物理异常；猜中也只看到绳尾、绕法和新麻毛，尚难形成“它被拆用过”的假说。
- 根因：人物与前史 v6 第 5.2.1 已规定的“景片高度不齐”没有写进剧情树；观察、犯忌、推断三步中缺了第一步。
- 相关岗位判断：continuity＝两份 v6 不同步；narrative＝线索因果链断一格；playtest＝高价值内容藏在低可达选项后；commercial＝最能展示民俗规则与主动越界的镜头容易完全不发生。
- 已有竞品/设计模式依据：GDC 的循环要求先给具体信息，再让玩家以行动证明理解；这里应先看见景片不齐，再自己决定是否上天桥。
- 商业影响：本作“班规既是恐怖规则也是推理工具”的卖点无法在 Demo 稳定成立。
- 建议修改方式：C05/C06 台侧增加不犯忌可见的景片高度异常；C12 若玩家见过它，选项改为“上天桥查那片不齐的景”；天桥仍不给勒颈答案。
- 制作成本：低。一个场景状态、一个可点热点与一条速记，可用现有画面表现。

### P0-05｜C18 四个疑点的可达性倒挂，药盒成为惩罚性默认答案

- 所在场次：C09—C12、C16、C18。
- 玩家实际体验：药盒冲突人人必得；路线差异、吊绳、离岗却依赖此前恰好选对位置。玩家最容易写出的恰好是最伤害玉棠、也最偏离真实死因的一条。
- 根因：系统惩罚的是“有没有抽到整条线”，而不是“证据强度允许写多满”；保底材料与真相距离不成比例。
- 相关岗位判断：narrative＝信息经济失衡；playtest＝合理玩家会被默认入口推向花边；commercial＝写稿盘看似自由，实际首周目高度收敛；dialogue＝现有提示没有明确区分动作事实与动机推断。
- 已有竞品/设计模式依据：GDC 演讲强调玩家必须能用已有动词表达自己实际理解的程度；《Golden Idol》访谈强调推理逻辑需要通过测试验证，而非只保证作者答案存在。
- 商业影响：玩家可能认为游戏故意诱导“写坏人”，而不是让自己对措辞负责。
- 建议修改方式：四个判断始终可见；弱材料只能形成更窄的句子，强材料才允许更强判断。药盒旁由编辑提醒“这是经过，不是用意”，但不阻止发表，也不预告后果。
- 制作成本：中。主要是 C18 的证据强度与文本变体，不新增全局分支。

### P1-06｜三个戏剧峰值连续拿走玩家输入

- 所在场次：C08、C11、C16。
- 玩家实际体验：林怀安失约时只能等；玉棠当众把矛头指向记者时只能说固定辩解；等待签字时四选一明显只有陈九生有硬价值。
- 根因：场景把重要动作都交给 NPC，玩家只在低压时选择位置，在高压时观看结果。
- 相关岗位判断：narrative＝冲突没有变成行动；dialogue＝公众指控缺少玩家应对；playtest＝“长期点继续”的感受集中在最该参与的段落；commercial＝命案段落可看但不够可玩。
- 已有竞品/设计模式依据：GDC 的“证明理解”不只等于填答案，也可以是去哪里、向谁说什么；本作已有六个动词足够，无需新增。
- 商业影响：主播和试玩者在最强剧情段没有个人化结果，传播内容趋同。
- 建议修改方式：C08 加“跟玉棠进通道/留在侧厅确认约见处”；C11 加“说明边界/沉默/反问依据”；C16 四人各提供不同调查方向的可用记录。
- 制作成本：中。状态与后续笔录差异，零新场景、零新系统。

### P1-07｜十一点半与警方到场前的时间压力目前是装饰

- 所在场次：S00、S02、C11—C12、C16—C17。
- 玩家实际体验：墙钟多次出现，但任何选择都不真正消耗机会；上天桥与留在药盒边成本相同，玩家不会把重要线索理解为“我为它放弃了别的东西”。
- 根因：人物与前史 v6 第 6.1.2 已规定“上天桥会错过 C16 一次观察”，剧情树尚未实现。
- 相关岗位判断：continuity＝v6 同步缺口；playtest＝时间语言未形成行为后果；narrative＝选择重量不足；production＝只需状态关闭和钟面推进，不需倒计时 UI。
- 已有竞品/设计模式依据：属于本作已定规则，不需要新竞品支持。
- 商业影响：Demo 的“末版压力”只能靠台词宣传，无法成为玩家实际感受。
- 建议修改方式：C12 选择上天桥后墙钟明显推进，并错过 C16 看一人的机会；不显示数字、不提前列出代价。
- 制作成本：低。

### P1-08｜第一章收尾有情绪，没有玩家自己的下一步

- 所在场次：C21—C22。
- 玩家实际体验：看见新旧报道并排后，知道别人会反应，却不知道自己第二章要主动查什么；继续追查欲主要依赖“还有秘密”，不是一个能立刻执行的问题。
- 根因：章末后果都是外部反馈，序章“采访函旁没有回函”的具体疑问没有回收。
- 相关岗位判断：narrative＝章尾缺行动钩；playtest＝完成后没有明确下一目标；commercial＝Demo 结束后的愿望单动机不够具体；production＝可复用报馆收发簿，不增加场景。
- 已有竞品/设计模式依据：GDC 的循环要求一次发现导向下一次行动；这里应从“没有回函”导向“查收发记录”。
- 商业影响：Demo 结束画面有气质，但“我还想亲手做什么”弱于“我想知道后续剧情”。
- 建议修改方式：保留新旧报并排，最后追加玩家主动标记：查报馆收发簿，确认林怀安是否回过信。
- 制作成本：低。

## 3. 应保留的现有内容

- S00 红笔圈出“显然”的退稿：开场、方法论、职业压力一次完成。
- S01 原件系统与六件桌面材料：来源清楚、知识边界正确，适合自由探索。
- S02 “带原件/抄录”及后续证物控制：选择改变纸面证据去向，不是装饰分支。
- C01 春和门前“不阴森”：避免廉价鬼屋预设，保留生活世界。
- C03 阿成带路与白线、景路、铁梯规则：用行动建立戏班行当隔阂。
- C04 林怀安只答应看材料，不承诺交代真相：知识边界准确。
- C06—C07 同一时段只能留一处观察：注意力有限的结构应保留，只修盲选。
- C09 一次性第一眼：非常适合做首周目差异与后续笔录依据。
- C10 药盒落地：动作、人物误读、秘密与公开冲突集中，是第一章最强戏剧场。
- C11 “旧疾/记者刺激”两个版本先传播：很好地表现官方叙事到场前已经被污染。
- C13—C15 警方封存、笔录、交不交函件、说不说吊绳：完整体现“决定谁知道什么”。
- C17—C21 写稿、选择依据、公开范围与次日后果：Demo 的核心差异化，不改为普通结案菜单。
- C22 新旧报标题并排：保留作为视觉收束，只补主动问题。

## 4. 只是实现残留，不是剧情本身的问题

以下内容不应被误报为 v6 剧情缺陷，也不在本轮修改：

- `README.md` 与 `content/剧情表使用说明.md` 仍写沈家旧宅、父亲遗物、父子合照和旧序章。
- 当前工作簿、生成 CSV、`game_state.gd`、`main.gd` 仍有旧阶段名、父子状态键和断裂入口。
- 运行数据尚未落入 C08 蒙镜、景片高度异常、C12 时间取舍与第一章速记书签。
- 当前 Godot 是占位 UI/色块，视觉 Bible 只在镜头承载和人物状态上提供约束，不代表剧情树需要新增 CG。

这些属于正式草案拍板后的同步与 Technical QA 范围；不能为了让当前实现跑通而反向改写本审查结论。

## 5. 审查结论

- P0：5 项。
- P1：3 项。
- P2：本轮不单列；对白润色与演出细节应在结构修补稳定后再做。
- 建议方向：保留案件与人物骨架，优先补“玩家先学会—有信息地观察—主动犯忌/应对—按证据强度写稿—带着问题结束”的连续行动链。
