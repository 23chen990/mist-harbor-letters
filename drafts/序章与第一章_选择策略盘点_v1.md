# 《雾港来信》序章与第一章选择策略盘点 v1

> 审查对象：`drafts/序章与第一章_工作草案_v13.md`  
> 状态：工作审查，不构成正式机制或剧情决策。  
> 目标：盘点 S00—C22 的全部玩家输入，而不是只检查 C04 回信诈话。

## 一、总体判断

v13 的选择数量并不少，真正的问题是**策略层分布不均**：

- 前半段有大量“选位置 / 点一个热点”，主要改变玩家拿到什么；
- 中段最适合操纵信息差的 C10、C16，要么自动替玩家说，要么只让玩家旁听；
- 后半段 C18、C19 用“疑点 / 公开范围”等作者分类代替玩家真正相信和刊出的句子；
- 因此玩家有观察路径，却很少感到自己在试探、压话、隐瞒、举证或控制公开顺序。

最严重的三处是：

1. **P0｜C10 自动公开赵敬文与采访函**：核心动词“决定谁知道什么”在最应该出现的时刻被固定对白夺走。
2. **P0｜C16 四条价值不等且玩家仍是旁听者**：陈九生有时间破绽，玉棠、许济川、方仲山主要交付态度，选项不在同一价值层。
3. **P0｜C18 / C19 没让玩家直接选择判断句与见报句**：玩家选的是设计分类，不是自己的推理和公开策略。

## 二、审查尺度

每个输入按六项检查：

1. 玩家此刻掌握什么；
2. 玩家是否在判断某人的知识、动机或位置；
3. 选择是门槛、观察、试探、隐瞒、举证还是发布；
4. 两边是否都有可理解的收益与代价；
5. 是否改变知识、态度、证物、警方记录、报道或后续条件；
6. 玩家是否能从选项文字本身理解自己正在做什么。

并非每次点击都必须是策略选择。门槛、转场和固定冲突可以线性；但只要文档把一个输入称为“选择”，它就必须有不同的玩家意图和后果。

## 四、选择链而不是孤立选项

### 链 1｜采访函的信息控制

```text
S02 带原件 / 抄录
→ C04 怎样试探、原件留不留
→ C10 当众说多少
→ C11 怎样应对玉棠的版本
→ C13 顾承钧先听见什么
→ C14 向警方核对内容、原件交不交
→ C19 是否把赵敬文联系公开
→ C21 方仲山是否知道记者公开到了哪里
```

v13 只有 S02、C04、C14、C19 在工作；C10 的固定全公开把中间链条截断。v14 首要修复这条链。

### 链 2｜观察如何变成压话依据

```text
C05 押一个位置
→ C06 / C07 取得局部观察
→ C09 决定第一眼
→ C12 再投入一次稀缺行动
→ C16 用看见的东西测试一个人的说法
→ C18 写下自己的临时判断
```

v13 的 C06—C09 有观察，但 C16 不读取这些观察，玩家此前的选择没有变成谈话优势。v14 将 C16 改成条件式追问，不增加新动词。

### 链 3｜私人判断如何变成公共事实

```text
C18 选择自己目前相信哪一句
→ C19 决定只留在案头、只公开当前疑点、或连赵敬文一起公开
→ C21 世界只回应实际刊出的原句
```

v13 的逻辑正确，表达层错误：玩家选的是“疑点 / 公开范围”标签。v14 改为直接显示判断句和见报句。

## 五、应该保留的内容

- S02 原件 / 抄录的证物差异；
- C04 回信试探与原件去向分离；
- C07 谢幕前后的不可兼得观察；
- C09 一次第一眼；
- C11 辩解、沉默、反问的公共位置差异；
- C12 三条时间取舍；
- C14 原件交警或自持；
- C15 报告吊绳或隐瞒；
- C20 单一交稿；
- C21 用人物和现场变化反馈，不给道德分；
- C22 把反应重新落回查纸核实。

这些部分不是“诈话不足”，不应为了增加策略而全部改成审讯菜单。

## 六、交互健康度

> 以下是对作者层交互结构的评估，不是对当前视觉 UI 的评分。

| 可用性维度 | 分数（0—4） | 主要问题 |
|---|---:|---|
| 状态反馈 | 3 | C21 较强，但 C10 的公开状态未被完整追踪 |
| 符合真实行动语言 | 2 | C18 / C19 使用设计分类，不是玩家会想或会写的话 |
| 玩家控制 | 2 | C10 自动泄露；C16 只能旁听 |
| 一致性 | 2 | 有些选择显示实际台词，有些显示抽象策略标签 |
| 避免误选 | 2 | C05 首次盲选；C04 第三句可能稳定最优 |
| 识别而非回忆 | 2 | C18 要玩家凭记忆判断，未把相关原句与选项并置 |
| 灵活性 | 2 | 观察路线多，但用观察压话的路径少 |
| 克制与简洁 | 3 | 整体已较 v4—v6 精简，C08 仍有一次冗余热点选择 |
| 错误后的恢复 / 后果 | 3 | 多数不立即失败，后果可持续；少数选项还没有真实代价 |
| 教学与帮助 | 2 | 不宜补说明文字，应靠首个策略选择本身教会玩家 |
| **总分** | **23 / 40** | **可用，但策略层需要一次结构修订** |

认知负担八项中，当前主要失败两项：

- **工作记忆**：C18 没有把判断与相应原句并置；
- **一致性**：实际台词、动作标签、作者分类三种选项格式混用。

总体为中等负担，不需要增加教程；需要把选项改成更接近玩家实际行动的文字。

## 七、三类玩家的失败点

- **第一次玩文字推理的玩家**：C05 只看见地名，无法知道自己在押什么；C18 又突然要从整晚内容中挑主题。
- **熟悉推理游戏的玩家**：会迅速发现 C04 第三句和 C16 陈九生明显信息量更高，选择退化为找最优按钮。
- **反复测试状态的玩家**：会发现 C10 无论前面怎样保护函件，都自动公开赵敬文联系；此前的保密策略因此失真。

## 八、制作成本

- 新 CG：0。
- 新背景：0。
- 新全局 UI：0。
- 新主角动词：0。
- 新全局分支：0。
- 所需改动：选择文本、少量条件对白、状态组合与 C18 / C19 句子映射。

## 九、验证标准

1. 玩家能复述 C10 三句分别让谁知道了什么；
2. C05 选择前能说出自己在押哪个人物或空间，但不知道答案；
3. C16 至少三条路径能使用此前观察改变问法；
4. C18 选项是完整临时判断，不是“药盒 / 路线”等主题标签；
5. C19 玩家能在点击前直接读到将刊出的句子；
6. 任一未公开信息都不会因固定对白自动传给方仲山或围观者；
7. 1917、未寄回信与 NPC 反应均不被系统认证为事实。
